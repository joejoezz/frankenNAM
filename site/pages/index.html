The 12 km NAM, kept running

On 3 November 2026 NCEP retired the NAM. FrankenNAM runs the same model code and physics twice a day on rented cloud computers and publishes the maps and the grids, with its limits stated on every product.

What you are looking at, stated plainly. FrankenNAM is initialized from the (C−6)Z GFS analysis with a 6 h NAM spin-up, where C is the cycle time. It has no data assimilation and no observations after (C−6)Z. It is not the operational NAM and it is not affiliated with NOAA.

The story

NCEP retired the 12 km NAM, its 3 km nests, SREF, HiresW and NAM MOS on 3 November 2026 at 12Z, replacing them with RRFS and REFS. Many forecasters leaned on the NAM for what it did well: winter-storm structure, cold-air damming, precipitation type, and soundings that fed BUFKIT.

The model's source code is US-government work and was public. NCEP's own copy came down on the day of retirement, but the NAM developers had published the full tree on GitHub, and the missing static files were recovered from web archive captures. The code was built on AWS and a full 84 h forecast on the original 954×835 North American grid was run for a historical cycle. That was the first proof that the model could be run outside NCEP at all, at a compute cost of a few dollars per run.

What could not be recovered is the NAM's data assimilation. Its analysis needs an 80-member ensemble that was never public. So FrankenNAM starts from another model's analysis, which is a real difference and the reason this page exists.

What it is, and what it is not

It is

  • The NAM v4.2 dynamical core (NMMB) and physics: Ferrier-Aligo microphysics, BMJ convection, MYJ boundary layer, Noah land surface.
  • The full 12 km North American parent domain, 60 levels, out to 84 h.
  • Run for the 00Z and 12Z cycles.
  • Output as GRIB2 on grid 218, with the same file names and .idx files as the operational NAM, so existing tools can be pointed at it.
  • Free maps for CONUS and regions. Grids are the paid part; see Subscribe.

It is not

  • The operational NAM. The analysis is different, so the first hours differ most.
  • Assimilating observations. Nothing after the (C−6)Z GFS analysis goes in.
  • The 3 km nests, fire-weather or Alaska, Hawaii and Puerto Rico domains. Only the 12 km parent is run.
  • A verified product yet. The scorecard is empty until live cycles have been scored, and no skill claim is made before then.
  • An official forecast. Use National Weather Service products for warnings and decisions that matter.

The delivery clock

For a 12Z cycle the run starts at 06Z from the 06Z GFS analysis, integrates 6 h of NAM physics to 12Z, and 12Z is forecast hour 0 of the product. The 00Z cycle works the same way from the 18Z analysis. In information content a FrankenNAM cycle therefore lags the GFS cycle of the same name by about 6 h.
