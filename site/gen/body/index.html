Why?

The 12 km NAM ran for over two decades, and forecasters still rely on it.

They reach for it for what it does well: cold-air damming and wedge setups, soundings, precipitation type, and mesoscale structure that coarser models smooth away. NOAA retired the NAM on 3 November 2026. The model's own code is a US-government work and was public, and one run costs under $3 on cloud hardware (measured: about $2.60 per cycle). Keeping it running is an inexpensive project that keeps providing value to the community.

FrankenNAM runs that code twice a day and says plainly what is different from the operational NAM. About FrankenNAM has the design; Validation has the numbers.
